# orqion

orqion — приложение для работы с языковыми моделями: чат с локальными или
внешними моделями, маршрутизация между провайдерами, поиск по собственным
документам (RAG) и ролевое разграничение доступа. Сервер на
Python (FastAPI), интерфейс — встроенное веб-приложение на React; в
минимальной конфигурации не требует ни Docker, ни внешних сервисов.

## Чем отличается от аналогов

Три опоры проекта:

- **Ролевая модель.** Предустановленные роли (администратор, менеджер,
  пользователь) и политики доступа; документы и корпусы маркируются классами
  данных К0–К3, доступ выдаётся с учётом класса. Разграничение действует на
  уровне интерфейса и на уровне поисковой выдачи.
- **Безопасная переиндексация.** Индекс собирается новой версией, пока старая
  продолжает обслуживать поиск. Версию можно активировать после проверки и
  откатиться к предыдущей, если новая оказалась хуже. Поиск не прерывается на
  время пересборки.
- **Оценка качества в интерфейсе.** Для корпуса создаётся набор контрольных
  вопросов; прогон оценки показывает, что и насколько точно находит индекс.
  Решение «активировать версию» принимается по измеренному качеству, а не по
  ощущениям.

## Установка за 5 минут

Требуется Python 3.12+ и Node.js 20+ (для сборки интерфейса).

```bash
git clone https://github.com/ChayannFamali/orqion.git
cd orqion

python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # Linux / macOS
pip install -e .

cd frontend
npm ci && npm run build       # собранный интерфейс отдаёт сам сервер
cd ..

orqion migrate                # создаёт схему базы данных
orqion serve                  # запускает сервер на 127.0.0.1:8000
```

Откройте `http://127.0.0.1:8000`. При первом запуске создаётся учётная запись
администратора — одноразово показанный пароль сохраните.

Это профиль `minimal`: база данных в файле SQLite, векторный индекс в
`sqlite-vec`, документы в локальной папке — без Docker и внешних сервисов.
Для продакшн-нагрузок доступны профили с PostgreSQL и Qdrant; см.
[guide/admin/](guide/admin/).

Чтобы чат заработал, подключите провайдер моделей — локальные
[LM Studio](https://lmstudio.ai) или [Ollama](https://ollama.com), либо любой
сервер с OpenAI-совместимым API: [guide/user/local-models.md](guide/user/local-models.md).

## Ограничения

Честный список того, чего проект пока не умеет (на момент версии 0.1.0):

- **Нет встроенного инференса.** Модели запускаются во внешнем сервере
  (LM Studio, Ollama) или подключаются по OpenAI-совместимому API.
- **Одноузловое развёртывание.** Встроенного горизонтального масштабирования
  нет; для роста нагрузки переключайтесь на PostgreSQL и отдельный
  векторный сервер (профили `standard` и `full`).
- **Встраивания (эмбеддинги)** считаются либо локальной библиотекой
  (дополнительная установка, требует заметного объёма памяти), либо
  провайдером моделей — см. раздел про эмбеддинги в
  [руководстве по подключению моделей](guide/user/local-models.md).
- **Поиск по документам: фрагменты вместо целого документа; без дополнения
  `full` работает в упрощённом режиме.** Ответ строится по ограниченному
  числу лучших фрагментов, поэтому вопросы вида «перескажи весь документ»
  и длинные перечни, разнесённые по файлу, могут раскрываться в ответе не
  полностью. Если проект установлен без дополнения `full`
  (`pip install orqion[full]`), локальный реранкер отсутствует: порядок
  фрагментов определяется суммарным рангом двух поисков, а порог
  релевантности из настроек поиска не применяется. Это осознанное поведение,
  а не сбой настройки — факт упрощённого режима фиксируется в трассировке
  каждого запроса.
- **Граф связей документов** требует дополнение `graph`
  (`pip install orqion[graph]`): без него раздел явно сообщает, что
  функция недоступна и требуется дополнительный компонент; поиск и
  остальные возможности работают как обычно.
- **Агентный модуль** требует дополнение `agent`
  (`pip install orqion[agent]`): без него агентные диалоги недоступны,
  обычный чат работает как прежде. Транзитивно через дополнение
  устанавливается клиент телеметрии `langsmith` — он выключен по
  умолчанию и активируется только переменными окружения `LANGSMITH_*`,
  которые проект не выставляет.
- Проект в стадии **предрелиза**: интерфейс и поведение могут меняться между
  версиями без обратной совместимости до выпуска 1.0.

## Roadmap

Запланировано, **не реализовано** (не скачивайте проект ради этих функций —
их ещё нет):

- **Агенты** — многошаговое выполнение задач моделью с инструментами.
- **Поддержка MCP-серверов** — подключение внешних инструментов по
  Model Context Protocol.
- **Граф связей корпуса** — навигация по связям между документами.

Сначала выпускается модель безопасности агента и инструменты аудита, затем —
сами агенты.
