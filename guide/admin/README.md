# Руководство администратора

- [Профили развёртывания](deployment.md) — minimal / standard / full,
  сетевое развёртывание и защищённые куки.
- [Переход на PostgreSQL](postgres.md) — реляционная база вместо SQLite.
- [Переход на Qdrant](qdrant.md) — отдельный векторный сервер вместо
  встроенного векторного хранилища.
- [Роли и политики](access.md) — встроенные роли, права, классы данных
  К0–К3.
- [Служебные настройки](settings.md) — что редактируется в интерфейсе,
  приоритет значений, валидация, журнал аудита.
- [Агенты](agents.md) — профили агентов, скиллы, серверы инструментов,
  ограничения прогона и безопасность.
- [Диагностика окружения](diagnostics.md) — что показывает раздел
  **Диагностика** и как читать его состояния.
- [Сроки хранения](retention.md) — что и сколько хранится, как настроить.
- [Резервные копии](backup.md) — backup и восстановление.

Большинство настроек задаётся переменными окружения с префиксом `ORQION_`
(в файле `.env` рядом с местом запуска или в окружении процесса).

Часть служебных настроек редактируется в интерфейсе — раздел **Настройки**,
вкладка **Общие**. Для такой настройки переменная окружения задаёт значение
по умолчанию: оно действует до первой записи в интерфейсе, после чего
приоритет имеет записанное значение. Личные настройки пользователя (раздел
**Профиль**) принадлежат каждому пользователю и через переменные окружения
не задаются.
