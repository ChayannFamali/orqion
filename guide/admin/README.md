# Руководство администратора

- [Профили развёртывания](deployment.md) — minimal / standard / full,
  сетевое развёртывание и защищённые куки.
- [Переход на PostgreSQL](postgres.md) — реляционная база вместо SQLite.
- [Переход на Qdrant](qdrant.md) — отдельный векторный сервер вместо

(в файле `.env` рядом с местом запуска или в окружении процесса).
