# Переход на Qdrant

По умолчанию векторы хранятся во встроенном хранилище (отдельный файл в
каталоге данных). Для профиля `full` и больших корпусов рекомендуется
отдельный векторный сервер [Qdrant](https://qdrant.tech).

Выбор векторного хранилища не зависит от реляционной базы: допустимы
сочетания SQLite + Qdrant и PostgreSQL + встроенное хранилище.

## Настройка

1. Установите зависимость:

```bash
pip install -e ".[vector-qdrant]"
```

2. Запустите Qdrant (например, в Docker):

```bash
docker run -p 6333:6333 qdrant/qdrant
```

3. Укажите настройки:

```env
ORQION_VECTOR_STORE=qdrant
ORQION_QDRANT_URL=http://localhost:6333
ORQION_QDRANT_API_KEY=<ключ, если включена авторизация>
```

4. Перезапустите сервер (`orqion serve`). Новые сборки индекса будут
   писаться в Qdrant.

## Переход со встроенного хранилища

Векторы существующих версий индекса не переносятся автоматически. После
переключения поиск по корпусам не найдёт ничего, пока для каждого корпуса
не будет собрана и активирована новая версия индекса — планируйте
переключение на время, когда пересборка допустима.
