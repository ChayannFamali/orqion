# Переход на PostgreSQL

PostgreSQL используется как реляционная база данных вместо SQLite
(профили `standard` и `full`). Векторное хранилище — отдельный выбор:
оно остаётся встроенным (отдельный файл) или переводится на Qdrant
независимо от базы данных.

## Переход

### 1. Установите зависимость

```bash
pip install -e ".[postgres]"
```

### 2. Укажите адрес базы

```env
ORQION_DATABASE_URL=postgresql://user:password@localhost:5432/orqion
```

Префикс `postgresql://` поддерживается как есть — драйвер подключается
автоматически.

### 3. Примените схему

```bash
orqion migrate
```

На пустой базе будут созданы все таблицы.

### 4. Перенесите данные (если уже работали с SQLite)

```bash
python backend/scripts/migrate_sqlite_to_postgres.py \
  --source "sqlite:///./orqion.db" \
  --dest "postgresql://user:password@localhost:5432/orqion"
```

Скрипт проверяет, что целевая база пуста, и копирует таблицы в порядке
внешних ключей. Фрагменты и векторы поиска не переносятся: они лежат в
отдельном файле векторного хранилища, который используется как прежде.

### 5. Запустите

```bash
orqion serve
```

## Особенности

- Полнотекстовый поиск по документам работает в отдельном файле
  векторного хранилища и не зависит от выбора реляционной базы.
- Для сетевого развёртывания с PostgreSQL выставьте
  `ORQION_SESSION_COOKIE_SECURE=true` — см.
  [профили развёртывания](deployment.md).
