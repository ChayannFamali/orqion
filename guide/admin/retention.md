# Сроки хранения

Часть данных очищается автоматически по возрасту. Пороги задаются
переменными окружения; `0` — хранить бессрочно.

| Данные | Настройка | По умолчанию |
|---|---|---|
| Записи трассировок | `ORQION_SPAN_RETENTION_DAYS` | 30 дней |
| События использования | `ORQION_USAGE_EVENT_RETENTION_DAYS` | 90 дней |
| Сообщения диалогов | `ORQION_MESSAGE_RETENTION_DAYS` | бессрочно (`0`) |

Очистка выполняется фоновой задачей; интервал —
`ORQION_RETENTION_CLEANUP_INTERVAL_SECONDS` (по умолчанию раз в час).

Диалоги по умолчанию не удаляются: переписку можно ограничить по сроку,
выставив `ORQION_MESSAGE_RETENTION_DAYS` в нужное число дней.

Настройки вступают в силу после перезапуска сервера.
