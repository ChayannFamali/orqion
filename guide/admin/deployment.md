# Профили развёртывания

Профиль задаётся переменной `ORQION_PROFILE` (`minimal`, `standard`,
`full`) и определяет состав компонентов и поведение по умолчанию.

## Сравнение профилей

| Компонент | `minimal` | `standard` | `full` |
|---|---|---|---|
| Назначение | один пользователь, локально | команда, сетевой сервер | то же + наблюдаемость |
| Реляционная БД | SQLite (файл) | PostgreSQL или SQLite | PostgreSQL |
| Векторное хранилище | встроенное (файл) | встроенное или Qdrant | Qdrant |
| Файлы документов | локальная папка | локальная папка или S3-совместимое хранилище | S3-совместимое хранилище |
| Технические метрики | — | опционально | включаются (дополнительная зависимость) |

`minimal` работает сразу после установки — без внешних сервисов.
`standard` и `full` отличаются рекомендуемым составом; конкретные
компоненты включаются отдельными настройками:

- **База данных:** `ORQION_DATABASE_URL` —
  [переход на PostgreSQL](postgres.md).
- **Векторное хранилище:** `ORQION_VECTOR_STORE=qdrant` —
  [переход на Qdrant](qdrant.md).
- **Файлы документов:** `ORQION_BLOB_STORE_BACKEND=s3` и настройки
  `ORQION_S3_*` (дополнительная зависимость: `pip install -e ".[s3]"`).
- **Технические метрики:** `ORQION_METRICS_ENABLED=true`
  (дополнительная зависимость: `pip install -e ".[metrics]"`),
  доступны на служебном адресе приложения.

## Сетевое развёртывание и защищённые куки

Если сервер доступен по сети (не только `127.0.0.1`), сессии должны
передаваться только по HTTPS.

> ⚠️ Для сетевого развёртывания обязательно выставьте
> `ORQION_SESSION_COOKIE_SECURE=true` и обеспечьте TLS (например,
> обратным прокси). Без этого сессионная кука может уйти по открытому
> HTTP.

Поведение по умолчанию: для профилей `standard` и `full` защищённые куки
включены автоматически; для `minimal` — выключены (расчёт на локальный
доступ). Явная `ORQION_SESSION_COOKIE_SECURE` всегда имеет приоритет.

## Секретный ключ

Ключ шифрования создаётся автоматически при первом запуске и хранится в
файле `.secret_key` в каталоге данных. При переносе на другую машину
сохраните этот файл — иначе сохранённые ключи провайдеров придётся вводить
заново. Альтернатива — задать ключ явно через `ORQION_SECRET_KEY`.

## Вход через внешний провайдер идентификации (опционально)

Поддерживается вход через OpenID Connect (дополнительная зависимость:
`pip install -e ".[oidc]"`): `ORQION_OIDC_ENABLED=true` и настройки
`ORQION_OIDC_CLIENT_ID`, `ORQION_OIDC_CLIENT_SECRET`,
`ORQION_OIDC_ISSUER`, `ORQION_OIDC_REDIRECT_URI`. Локальный вход по
паролю при этом продолжает работать.

## Запуск под нагрузкой

Для нескольких одновременных пользователей достаточно одного процесса
(`orqion serve`). Для большей нагрузки используйте менеджер процессов
с несколькими воркерами (например, `uvicorn app.main:app --workers N`)
и обратный прокси перед приложением.
