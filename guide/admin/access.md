# Роли, политики и классы данных

## Встроенные роли

При первом запуске создаются пять ролей. Каждая задаёт политику:
доступные модели, лимиты запросов и токенов, бюджет, права в интерфейсе.

| Роль | Кому подходит | Права в интерфейсе |
|---|---|---|
| `support` | минимальный доступ | только чат, локальные модели, жёсткие лимиты |
| `developer` | повседневная работа | чат, загрузка документов, трассировки; локальные и внешние модели |
| `architect` | расширенная работа | то же + управление корпусами, доступ к закрытым корпусам, выше лимиты |
| `manager` | работа и аналитика | чат, загрузка, аналитика использования, трассировки |
| `admin` | администрирование | всё без ограничений, включая провайдеров, роли, пользователей, аудит |

Политика роли включает также: максимум токенов на вход и выход в одном
запросе, месячный бюджет токенов/стоимости, частоту запросов в минуту.

Роли редактируются в разделе **Роли**: можно скорректировать права и
лимиты встроенной роли или создать собственную и назначить её
пользователю в разделе **Пользователи**.

Первого администратора сервер создаёт сам; дальнейших пользователей
создаёт администратор в интерфейсе или из командной строки:

```bash
orqion createuser --email user@example.com --role developer
```

## Классы данных (К0–К3)

Каждый корпус маркируется классом данных; класс определяет, какие модели
могут работать с содержимым корпуса:

| Класс | Содержимое | Модели |
|---|---|---|
| **К0** | публичные материалы | локальные и внешние |
| **К1** | внутренние рабочие материалы | локальные и внешние |
| **К2** | персональные данные | только локальные; модель закрепляется за корпусом |
| **К3** | коммерческая тайна | только локальные; модель закрепляется за корпусом |

«Только локальные» означает, что запросы с содержимым корпуса не уходят
на внешние сервисы. Для корпусов К2/К3 выберите закреплённую модель при
создании корпуса.

Понижение класса (например, К2 → К0) интерфейс подтверждает отдельным
шагом.

## Видимость разделов

Пункты меню видны по правам роли: пользователю без права управления
корпусами раздел управления не показывается и недоступен по адресу.
