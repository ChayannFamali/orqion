# Корпуса и документы

Корпус — набор документов, по которым работает поиск (RAG). У каждого
корпуса свои документы, свои версии индекса и свои наборы оценки.

## Создание корпуса

Раздел **Корпуса** → «Добавить». Поля:

- **Имя** — как корпус виден в интерфейсе и в чате.
- **Класс данных** — маркировка содержимого:
  - **К0** — публичные материалы;
  - **К1** — внутренние рабочие материалы;
  - **К2** — персональные данные (обслуживаются только локальными
    моделями, модель фиксируется в корпусе);
  - **К3** — коммерческая тайна (тоже только локальные модели).

Класс можно поменять позже; при понижении класса интерфейс попросит
подтверждение.

## Загрузка документов

Откройте корпус и загрузите файлы. Поддерживаются:

- документы: `.pdf`, `.docx`, `.pptx`, `.xlsx`;
- текст: `.md`, `.txt`;
- исходный код: `.py`, `.cpp`, `.ts`, `.go`, `.java`, `.sql`.

Лимит — 50 МБ на файл. Каждый документ проходит разбор; в списке виден
статус: **В очереди**, **Индексируется**, **Готов**, **Ошибка**,
**К удалению**.

### Удаление документа

Документ, по которому уже построены фрагменты индекса, не исчезает из
поиска мгновенно: он помечается **К удалению**, перестаёт попадать в новые
сборки индекса и удаляется полностью после очередной пересборки. Это
сделано намеренно — активная версия индекса остаётся цельной, и на неё
можно откатиться.

## Импорт git-репозитория

Репозиторий можно загрузить в корпус из командной строки:

```bash
orqion ingest-git https://github.com/user/repo.git --build-index
```

Команда клонирует репозиторий (по умолчанию — свежее состояние, без
истории), загружает исходные файлы в корпус с именем репозитория и сразу
строит индекс. Настройки глубины клона, лимитов и расширений —
`orqion ingest-git --help`.

## Версии индекса

Внутри корпуса — **Версии индекса**. Индекс строится версиями:

1. «Собрать» — запускает новую версию. Пока она собирается, поиск
   продолжает работать на текущей активной версии.
2. «Активировать» — переключает поиск на собранную версию.
3. Если новая версия оказалась хуже — откатитесь к предыдущей.
4. «Удалить старые версии» — очищает версии, которые уже заменены или были
   прерваны.

Порядок «собрать → проверить оценкой → активировать» описан в
[руководстве по оценке качества](evaluation.md).

## Вопрос по корпусу

Раздел **Чат**: выберите модель и отметьте один или несколько корпусов.
Вопрос уходит модели вместе с фрагментами из выбранных корпусов; в ответе
видны источники — фрагменты, на которых ответ основан.

Корпус без активной версии индекса в поиске не участвует.
