# Агентные диалоги

В обычном чате модель отвечает на вопрос один раз, используя найденные
фрагменты документов. В агентном диалоге модель сама решает, к чему
обратиться: прогон идёт циклом «модель → инструменты → модель», пока
задача не решена или не исчерпан лимит. Каждый шаг виден в блоке «Шаги
агента» под ответом.

Агентный режим устанавливается отдельным дополнением:

```bash
pip install orqion[agent]
```

Без него интерфейс сообщает о недоступности явно, а не выглядит как сбой.

## Как начать

Два способа:

- **Раздел «Агенты»** — выберите профиль и нажмите «Начать диалог».
  Профиль закрепляет модель и скилл, поэтому в диалоге их селекторы
  скрыты: диалог работает строго в заданной конфигурации.
- **Раздел «Чат»** — нажмите «Агентный диалог» и выберите модель и скилл
  вручную. Так создают диалог без профиля.

Для агентного диалога подходят не все модели: в списке выбора показаны
только модели с поддержкой инструментов. Если такой модели нет, кнопка
«Агентный диалог» в разделе «Чат» не появляется вовсе — добавьте модель в
разделе **Провайдеры**.

## Инструменты

Встроенный инструмент один — поиск по выбранным корпусам документов. Он
только читает: ничего не изменяет и не удаляет.

Дополнительные инструменты подключает администратор в разделе **Серверы
инструментов**; после этого они доступны в прогоне наравне со встроенным.

Скилл сужает набор инструментов прогона. Если в скилле список
инструментов пуст, прогон идёт вообще без инструментов — модель отвечает
только своими знаниями и инструкцией скилла.

## Остановка прогона

Во время прогона доступна кнопка «Остановить». Она ставит запрос: текущий
шаг дорабатывается, следующий не начинается. Ответ сервера на нажатие —
«запрос принят», а не «прогон остановлен»: факт остановки подтверждает сам
прогон, когда дойдёт до границы шага. В диалоге появляется сообщение
«Прогон остановлен по запросу пользователя: текущий шаг доработан,
следующий не начинался», а вопрос сохранён — лента честно показывает, чем
прогон завершился. История шагов при этом не теряется.

## Подтверждение действий

Деструктивный вызов внешнего инструмента (такой, который что-то меняет во
внешней системе) не выполняется сразу: прогон останавливается и показывает
карточку с именем инструмента и его параметрами. Кнопка «Выполнить»
разрешает вызов, «Отменить» — нет; в обоих случаях решение уходит
следующим запросом, прогон продолжается и даёт ответ. Без вашего решения
действие не выполняется.

## Защита содержимого

Для корпусов с классом данных К2 и К3 (персональные данные и коммерческая
тайна) вынос содержимого во внешние сервисы запрещён: внешние инструменты
в таком прогоне недоступны вовсе — весь их набор отклоняется до любого
обращения к серверам, а встроенный поиск по корпусу продолжает работать.
См. [классы данных](../admin/access.md).

## Ограничения прогона

Число шагов и суммарный расход токенов за прогон задаёт администратор
переменными окружения. При исчерпании ограничения прогон прерывается с
явной ошибкой и указанием достигнутого предела — молча обрывать прогон
сервер не будет.
