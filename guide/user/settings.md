# Настройки и профиль

Настройки делятся на две области: **Настройки** — параметры всей рабочей
области, **Профиль** — ваши личные параметры.

## Настройки

Раздел **Настройки** содержит три вкладки.

### Поиск по документам

Параметры подбора фрагментов для ответа:

| Параметр | Диапазон | Что делает |
|---|---|---|
| Порог релевантности после реранкинга | 0–100 % | Фрагменты с оценкой ниже порога не попадают в контекст; 0 — фильтр выключен |
| Максимум фрагментов контекста | 1–8 шт. | Сколько фрагментов передаётся модели |
| Число групп графа документов | 2–20 | На сколько семантических групп делить документы на графе связей |

Вкладка видна всем, но поля доступны для изменения только при праве
управления корпусами; остальным они показаны только для чтения.

### Общие

Служебные настройки рабочей области, сгруппированные по категориям:
**Сессии и безопасность**, **Файлы и хранение**, **Модель по умолчанию**.

| Настройка | Категория | Диапазон |
|---|---|---|
| Срок жизни сессии (дней) | Сессии и безопасность | 1–365 |
| Максимальный размер файла (МБ) | Файлы и хранение | 1–1024 |
| Разрешённые расширения файлов | Файлы и хранение | список через запятую |
| Температура генерации по умолчанию | Модель по умолчанию | 0–2 |

Рядом с каждым значением стоит метка его источника: **по умолчанию** или
**изменено**. Право на изменение этих настроек есть не у всех: без него
поля видны только для чтения. Как устроен механизм и что делает каждая
настройка — в [руководстве администратора](../admin/settings.md).

Изменённое значение применяется сразу, перезапуск сервера не нужен.

### Шаблоны промптов

Личные текстовые шаблоны: готовые формулировки вопросов и системные
инструкции. Вкладка видна при праве `custom_prompts` (оно входит во
встроенные роли `developer`, `architect` и `manager`); шаблоны принадлежат
вам, и другие пользователи их не видят.

## Профиль

Раздел **Профиль** — ваши личные настройки. Они доступны каждому
вошедшему пользователю независимо от служебных прав, действуют только на
вас и не влияют на остальных.

### Оформление

**Тема оформления** — светлая или тёмная. Значение сохраняется в этом
браузере: на другом устройстве тему нужно выбрать заново.

### Чат

**Отправка сообщения** — какое сочетание клавиш отправляет сообщение:

- `Enter` — отправить, `Shift+Enter` — новая строка;
- `Shift+Enter` — отправить, `Enter` — новая строка.

Настройка действует во всех диалогах, включая агентные, а подсказка в
поле ввода меняется вместе с режимом.
