# Быстрый старт

За 10 минут — от установки до первого ответа по вашим документам.

## 1. Установка

Инструкция — в [README](../../README.md): Python 3.12+, сборка интерфейса,
`orqion migrate`, `orqion serve`. Сервер поднимется на
`http://127.0.0.1:8000` — он же отдаёт и веб-интерфейс.

При **первом запуске** сервер создаёт администратора `admin@orqion.local` и
один раз печатает пароль в консоль. Сохраните его — повторно он не
показывается. Если пароль утерян: `orqion reset-password --email admin@orqion.local`.

## 2. Подключите модель

Без подключённого провайдера чат не работает. Самый быстрый путь — локальные
модели через LM Studio или Ollama: [Подключение локальных моделей](local-models.md).

Если коротко: раздел **Провайдеры** → добавить провайдер с адресом вашего
сервера моделей → в реестре моделей провайдера отметить модели, с которыми
будете работать.

## 3. Создайте корпус и загрузите документы

**Корпус** — набор документов, по которым работает поиск. Раздел **Корпуса**
→ «Добавить»: укажите имя и класс данных (К0 — публичные материалы,
К1 — внутренние рабочие, К2/К3 — персональные данные и коммерческая тайна).

Откройте корпус → загрузите файлы. Поддерживаются:
`.pdf`, `.docx`, `.pptx`, `.xlsx`, `.md`, `.txt`, а также исходный код:
`.py`, `.cpp`, `.ts`, `.go`, `.java`, `.sql`. Лимит — 50 МБ на файл
(настраивается).

## 4. Постройте индекс

Внутри корпуса — кнопка **Версии индекса** → «Собрать». Сборка разбирает
документы на фрагменты и считает векторы; текущий поиск (если он уже был)
продолжает работать на старой версии, пока новая не активирована.
Когда сборка завершится — нажмите «Активировать».

## 5. Задайте вопрос

Раздел **Чат**: выберите модель, отметьте корпус (можно несколько), задайте
вопрос. Ответ приходит с фрагментами из документов корпуса, на которых он
основан.

## 6. Проверьте качество

Прежде чем полагаться на поиск, прогоните оценку качества: корпус →
**Оценка качества** → набор контрольных вопросов → прогон на версии
индекса. См. [Оценка качества](evaluation.md).
