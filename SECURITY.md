# Безопасность

## Как сообщить об уязвимости

Не создавайте публичный issue. Используйте **приватный механизм
сообщения об уязвимостях на GitHub**:

1. Откройте вкладку **Security** репозитория
   [ChayannFamali/orqion](https://github.com/ChayannFamali/orqion).
2. Нажмите **«Report a vulnerability»** — откроется черновик приватного
   GitHub Security Advisory.
3. Опишите проблему: что происходит, шаги воспроизведения, затронутая
   версия или коммит, при наличии — оценка влияния.

Сообщение видно только сопровождающим проекта; публичным оно становится
только после исправления и раскрытия по решению сопровождающих.

## Сроки реакции

Проект в стадии предрелиза, поэтому сроки пока ориентировочные:

- подтверждение получения — **3 дня**;
- первичная оценка и план — **7 дней**;
- исправление критичных уязвимостей — по возможности в течение
  **30 дней**; по менее критичным — в ближайший выпуск.

Если подтверждение не пришло в течение недели — продублируйте сообщение.

## Поддерживаемые версии

| Версия | Получает исправления безопасности |
|---|---|
| текущая ветка `main` (до выпуска 1.0) | да |
| более старые снимки | нет |

До выпуска 1.0 исправления выходят в `main`; обновляйтесь до актуального
состояния ветки.

## Что считается уязвимостью

В том числе: обход разграничения доступа и ролей, утечка содержимого
корпусов между пользователями, чтение чужих диалогов и документов,
подмена или кража сессии, внедрение кода через загружаемые документы,
небезопасные значения по умолчанию при сетевом развёртывании.
